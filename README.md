# Concrete Driveway Maintenance: A Seasonal Checklist

A seasonal maintenance guide for concrete driveways: spring to winter checklists, safe pressure washing, sealer types and renewal cycles with a worked quantity example, joint and crack care, and first responses for oil, rust and tannin stains.

## Deploying this page

The finished page is `index.html`, a single self-contained file with no external assets. It can be deployed as a static site (GitHub Pages, Vercel or Netlify) or served through the included Streamlit app (`app.py`, needs `streamlit` from `requirements.txt`).
